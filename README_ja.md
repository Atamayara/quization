# Quization

Quization は、スマートフォンを早押し端末として使えるリアルタイムクイズシステムです。  
プレイヤー画面、司会者画面、大画面表示画面を WebSocket で連携します。

## 主な機能

- プレイヤー参加・再参加（ローカルストレージに参加情報を保存）
- WebSocket によるリアルタイム通信
- 早押し順の判定と応答時間の表示
- 正解・不正解の判定、得点・正答数・不正解数の管理
- 不正解時の休止設定
- 問題文の読み上げ速度、正解・不正解ポイントの変更
- 問題文・解答・選手スコア・早押し演出を大画面表示
- 正解・不正解・早押し・クイズ開始の効果音

## 画面構成

| 画面 | URL | 用途 |
| --- | --- | --- |
| プレイヤー | `/` | ニックネーム登録と早押し |
| 司会者 | `/host/` | 問題進行、得点・休止設定、正誤判定 |
| 表示用 | `/view/` | 問題、解答、早押し、スコア、演出を表示 |

司会者画面と表示用画面には、サーバーへ接触した端末がローカルホストの場合のみ接続できます。プレイヤー画面は、サーバーへ到達できる他の端末から利用できます。

## 使用技術

- Frontend: React 19、TypeScript、Vite、React Router
- Backend: Deno
- Communication: WebSocket
- Other: Deno Standard Library

## 必要環境

- Node.js（npm）
- Deno
- モダンブラウザ

この手順では、サーバー・司会者画面・表示用画面をホストPCで動かし、プレイヤーは同じLAN内のスマートフォンや別端末から接続します。司会者画面と表示用画面はサーバー側で localhost 接続する必要があります。LAN内の別端末からこれらの画面を開くことはできません。

## 起動方法

### 1. クライアントをビルドする

ホストPCでリポジトリのルートを開き、クライアントの依存関係をインストールしてビルドします。

```bash
cd client
npm ci
npm run build
```

ビルド成果物は `server/public` に出力されます。フロントエンドのソースを変更した場合は、サーバーを起動する前に再度ビルドしてください。

### 2. 問題データを用意する

問題データは `server/quiz.tsv` に置きます。このファイルは `.gitignore` 対象のため、リポジトリを新しく取得した場合は、後述の形式で自分で作成してください。

### 3. ホストPCでサーバーを起動する

ターミナルでサーバーを起動します。ターミナルはサーバー稼働中そのまま開いておきます。

```bash
cd server
deno task dev
```

サーバーはポート `8000` で待ち受けます。ホストPC上のブラウザで司会者画面と表示用画面を開いてください。

- 司会者: `http://localhost:8000/host/`
- 表示用: `http://localhost:8000/view/`

### 4. LAN内のプレイヤー端末から参加する

ホストPCのLAN内IPアドレスを調べ、スマートフォンなどのブラウザで `http://<ホストPCのIPアドレス>:8000/` を開きます。たとえばIPアドレスが `192.168.1.20` の場合は `http://192.168.1.20:8000/` です。プレイヤー端末もホストPCと同じLANに接続してください。

macOSでは、ターミナルで次のコマンドを実行すると、Wi-FiのIPアドレスを確認できます（環境によってはネットワークインターフェース名が異なります）。

```bash
ipconfig getifaddr en0
```

### 接続できないとき

- サーバーのターミナルでエラーが出ていないか確認してください。
- ホストPCとプレイヤー端末が同じLANに接続されているか確認してください。ゲストWi-Fiや端末間通信を遮断するネットワークでは接続できない場合があります。
- ホストPCのファイアウォールで、LANからの TCP ポート `8000` への接続が許可されているか確認してください。
- 司会者画面と表示用画面は、ホストPC上で `localhost` を使って開いてください。LAN内IPアドレスで開くと、ローカル接続制限により操作画面が接続できません。

このサーバーはLAN内での利用を想定しています。ルーターのポート転送などを設定して、インターネットに直接公開しないでください。

### 開発時の注意

フロントエンドのソースは `client/src`、ビルド成果物は `server/public` です。

WebSocket 接続先は画面を開いた URL のホスト名とポート `8000` です。現行のクライアントは `ws://` を使用するため、HTTPS環境では混在コンテンツとして接続できない場合があります。

## 問題データ

`server/quiz.tsv` を作成または編集します。各行をタブ区切りで「問題文」と「解答」にしてください。ファイルは UTF-8 で保存してください。

```tsv
日本の首都はどこですか？	東京
太陽系で最も大きい惑星は？	木星
```

サーバー起動時にファイルを読み込みます。起動後に問題データを変更した場合は、サーバーを再起動してください。

## 操作方法

1. ホストPC上で表示用画面と司会者画面を開く。
2. プレイヤー端末から `http://<ホストPCのIPアドレス>:8000/` を開き、ニックネームを入力して参加する。
3. 司会者画面の `▶️` で問題読み上げを開始する。
4. プレイヤーが早押しボタンを押す。
5. 表示された最初の回答者を司会者画面で `⭕️` または `✖️` 判定する。
6. `⏭️` で次の問題へ進む。

司会者画面では、次の設定を変更できます。

- `Speed`: 問題文の表示速度
- `Rest`: 不正解時の休止問題数
- `Point`: 正解・不正解時の得点
- 選手ごとのスコア

## スクリプト

### クライアント

`client` ディレクトリで実行します。

```bash
npm run dev     # Vite 開発サーバー
npm run build   # 本番ビルド
npm run lint    # ESLint
npm run preview # ビルド結果のプレビュー
```

### サーバー

`server` ディレクトリで実行します。

```bash
deno task dev
```

## ディレクトリ構成

```text
.
├── client/          # React フロントエンド
│   └── src/
│       ├── pages/   # プレイヤー、司会者、表示用画面
│       └── hook/    # WebSocket・効果音フック
├── server/          # Deno サーバー
│   ├── public/      # クライアントのビルド成果物
│   ├── main.ts
│   ├── gameMaster.ts
│   └── quiz.tsv
└── shared/
    └── types.ts     # クライアント・サーバー共通型
```
